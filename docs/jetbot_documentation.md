# JetBot AI Kit Documentation

## Package Overview

* **Product Name:** JetBot AI Kit (Complete Bundle)
* **Compatibility/Controller:** Powered by the NVIDIA Jetson Nano
* **Operating System:** Ubuntu 18.04 LTS (via included MicroSD)
* **Programming Environment:** Python
